# Changelog — versão 1.5

## Interface

- substituição completa do layout Permission Nexus;
- adoção do layout Enterprise Console baseado na referência aprovada;
- novo menu lateral e nova barra superior;
- novo dashboard com indicadores e painéis laterais;
- novo console do processo;
- labels explicativas em campos, filtros, botões e matriz;
- filtro de perfil mantido como `select`;
- novo modal de inclusão e edição de perfil;
- nova experiência responsiva.

## Domínio

- inclusão do campo `area` no processo;
- migração de compatibilidade para bancos SQLite existentes;
- inclusão da área nas exportações e no payload serializado.

## Qualidade

- 5 testes automatizados aprovados;
- compilação dos módulos Python aprovada;
- renderização desktop e mobile verificada;
- API e regras anteriores preservadas.
