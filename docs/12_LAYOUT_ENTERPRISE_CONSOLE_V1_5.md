# Layout Enterprise Console — versão 1.5

## Direção visual

A interface foi construída a partir do layout de referência aprovado, com foco em software corporativo de operação:

- navegação lateral permanente;
- barra superior com contexto global;
- alta densidade informacional sem excesso de elementos decorativos;
- bordas discretas e raios pequenos;
- amarelo CAEd reservado para ação principal e seleção;
- grafite para navegação e contraste institucional;
- textos de ajuda incorporados ao fluxo, sem balões invasivos.

## Dashboard

O dashboard apresenta:

- indicadores executivos;
- lista de processos;
- busca e filtro por status;
- atividades recentes;
- fila de aprovação;
- saúde do conector Bizagi.

## Console do processo

O console apresenta:

- resumo do processo;
- ações de salvar, enviar e sincronizar;
- identificação editável;
- labels explicativas para cada campo;
- filtro de perfil em `select`;
- matriz de permissões;
- rastreabilidade;
- fluxo de aprovação.

## Acessibilidade e usabilidade

- labels associadas aos campos;
- textos de ajuda curtos e objetivos;
- estados de foco visíveis;
- contraste elevado;
- tooltips nas colunas da matriz;
- operação por teclado;
- comportamento responsivo.
